# 开张，大有可爱。

给猫咪开张做的一支概念广告。纯白影棚里，从单只猫的展示、摸头和口袋镜头，展开成五套造型的阵列，最后拉远淡出。

## 做法

根据原项目和制作记录整理。这次归档的视频对应浅橘版，使用 Toonflow + 秘塔的 `MiniMax-H3` 生成，再用 FFmpeg 处理和拼接。

### 1. 先确认猫的样子

根据实拍照片生成并确认白底参考图，保留开张的小粉鼻、浅奶油橘金色长毛、柔和浅橘纹路、白胸白爪和整条浅金色尾巴。视频以这张图作为外形参考，避免把条纹加深成黑灰色。

### 2. 生成前 14 秒

在 Toonflow 中连接参考图，填入[前段提示词](prompts.md)并生成。两段使用相同配置：

| 参数 | 当时使用的值 |
| --- | --- |
| 供应商 | 秘塔，`metaso` |
| 模型 | `MiniMax-H3` |
| 请求时长 | 每段 14 秒 |
| 分辨率与比例 | `2K`，`16:9` |
| 模式 | 参考图模式，本次实际只连接图片参考。 |
| 声音 | `generateAudio: true`，在提示词中要求钢琴、木琴和轻微动作音效，无旁白、对白或演唱。 |

前段安排了拉远展示、摸头、口袋和五猫阵列。五套造型依次是原版、白 T、灰卫衣、透明外套、绿色恐龙外套。字幕也直接写进生成提示词。

### 3. 用前段尾帧接着生成后 14 秒

从前段生成视频提取最后一帧，作为后段的参考图。后段先承接五猫阵列，再横移经过衣服，回到单猫画面，最后拉远淡至全白。完整内容见[后段提示词](prompts.md)。

这版用的是参考图模式，尾帧用于提供衔接参考；原项目中后来另做的首帧锁定版没有收录在这里。

### 4. 统一时长和声音，再拼接

两段原始生成视频实际各为 14.375 秒。用 FFmpeg 将画面和音频同步调整至每段 14 秒，统一到 24 fps，并给声音加淡入淡出：

- 画面：`setpts=PTS*14/14.375,fps=24,setsar=1`。
- 音频：`atempo=1.026785714`，截取到 14 秒。
- 前段声音淡入 0.2 秒，末尾淡出 0.15 秒；后段声音淡入 0.15 秒，最后 2 秒淡出。
- 编码：`libx264`、`CRF 18`、`preset fast`；音频为 `AAC 192k`。
- 将处理后的两段按顺序无损拼接，启用 `+faststart`。

## 这版的不足

参考图和尾帧衔接能提供外形与构图依据，但无法保证每个镜头的猫脸、毛色和服装都完全一致。原制作记录也发现了脸型漂移；提示词中的约束不能当作成片已经全部达到的效果。

归档保留了提供的视频原文件。其音视频流与原项目浅橘版成片一致，没有重新压制。

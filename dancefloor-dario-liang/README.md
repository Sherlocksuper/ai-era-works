# 舞池对视：Dario 与肌肉梁

一段 15 秒的 AI 虚构恶搞视频：楼上的 Dario 靠着栏杆看向舞池，楼下的蓝西装肌肉梁一边跳舞，一边抬眼与他对视。参考抖音同类视频，重点模仿越肩俯看舞池、俯拍舞者和最后对视的镜头关系。

## 做法

根据这版成片对应的生成请求、剪辑记录和文件实测整理。

### 1. 按原片拆分三个镜头

用 FFmpeg 拆分[抖音参考视频](https://www.douyin.com/video/7696117893247496104)，提取每镜起始画面与原音轨。三个镜头分别是：

| 成片时间 | 画面 |
| --- | --- |
| 0–4.933333 秒 | 楼上人物靠栏杆，从带笑逐渐转为认真，镜头推进。 |
| 4.933333–10.100000 秒 | 从楼上人物后脑大近景，越肩向下俯看拥挤舞池。 |
| 10.100000–15.066667 秒 | 从前上方斜俯拍楼下舞者，边跳舞边抬眼。 |

### 2. 先换起帧里的人，再生成动态

用 imagegen 编辑原片的三个起始画面。楼上换成短卷发、眼镜、灰色针织开衫的 Dario；楼下换成蓝西装、白衬衫、宽厚肩胸的肌肉梁。

角色参考图提供外观，原片画面提供构图和机位。最后一镜特别保留头顶、双肩上表面可见的俯拍透视，避免变成胸口高度的正面拍摄。

随后通过 Toonflow 调用秘塔服务的 `MiniMax-H3`，分别输入换好人的图片和对应原片片段：

| 参数 | 实际设置 |
| --- | --- |
| 供应商 / 模型 | `metaso` / `MiniMax-H3` |
| 请求时长 | 第一镜 5 秒、第二镜 6 秒、第三镜 5 秒。 |
| 分辨率 / 画幅 | `768P` / `9:16`。 |
| 模式 | 第一、第三镜各 1 张图片 + 1 段视频；第二镜 2 张图片 + 1 段视频。 |
| 声音 | `generateAudio: false`；后期使用参考原片音轨。 |

第二镜第一次生成保留了原舞者。保留这段已生成的运镜，再用 imagegen 将远景中心人物改成蓝西装肌肉梁，作为修正后的远景参考图，另生成一次 6 秒素材。成片采用修正后的第二镜。

### 3. 按原片切点剪接，放回原声

用 FFmpeg 将三段画面从 768×1344 居中裁为 756×1344，统一到 30 fps，再依次截取前 148、155、149 帧。正常速度播放，没有加速或循环。

主要处理为 `crop=756:1344:6:0,fps=30,trim=end_frame=N,setsar=1`，三段再通过 `concat` 拼接。画面以 `libx264`、`CRF 17`、`preset medium` 编码；原音轨使用 `-c:a copy`，启用 `+faststart`。

最终切镜在 4.933333 秒和 10.100000 秒，与原片一致。原声 AAC 数据对比一致。归档直接复制确认采用的成片，没有重新压制。

### 4. 维护预览项目

HyperFrames 用于维护可预览的视频项目并检查加载、布局等问题；检查通过，0 错误。人物动态画面由 MiniMax-H3 生成，最终剪接与音轨封装由 FFmpeg 完成。

## 效果与不足

这版按原片三个镜头分别生成，连续抽帧确认了最后一镜的俯拍视角，以及远景和近景的蓝西装人物。机位、角色和动作仍是生成式模仿，人物细节、背景舞客、舞步与运镜轨迹无法保证逐帧一致。

提示词中的“精确”“完全不变”等内容是生成要求，不代表实际输出已全部达到。制作记录完成了连续抽帧、切点和音轨核对，未记录完整动态观看与听审。
